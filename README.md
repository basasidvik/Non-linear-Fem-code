Nonlinear FEM beam modeling with modal analysis, geometric stiffening, frictional contact, hysteresis, and energy dissipation.

This project presents a two-stage nonlinear finite-element study of beam dynamics using MATLAB.

Stage 1: A simply supported Euler–Bernoulli beam is analyzed using FEM to compute natural frequencies and mode shapes, validate results against analytical solutions, and simulate geometrically nonlinear vibration caused by von Kármán mid-plane stretching.

Stage 2: A cantilever beam extension introduces unilateral frictional contact at the free end. The model evaluates contact-force hysteresis, energy dissipation, stress–strain response, and the influence of contact stiffness using a reduced-order modal formulation. A MATLAB GUI is also included for interactive analysis.
